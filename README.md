# BMatrix releases and user guide

BMatrix is a Matrix client for Android phones and tablets running Android 10 or
later. This public repository contains APK releases, corresponding-source
archives, checksums, update metadata, and the user guide. Application
development and its Git history remain in a separate private repository.

## Downloads

Download APKs from [GitHub Releases](https://github.com/tibarbosa/bmatrix-releases/releases).
Choose the APK for your device ABI and follow the [installation guide](https://tibarbosa.github.io/bmatrix-releases/).
Never install an APK from an unofficial mirror. Keep the installed app when
updating so Android can verify the release signature and preserve local data.

## Documentation

Read the [BMatrix user guide](https://tibarbosa.github.io/bmatrix-releases/).
It records supported features and current limitations; a development preview
is not a stable release.

## Corresponding source

Each application release includes a `BMatrix-<version>-source.tar.gz` archive
containing the application/build inputs for that binary. It is prepared from a
tagged source snapshot without private Git history, personal data, credentials,
or server configuration. The project has not yet completed its distribution
license audit; do not treat this preview archive as a redistribution grant.
Review the license notices included in a future stable release before
redistribution.
